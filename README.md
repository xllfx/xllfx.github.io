# 网址导航站（一为风格）

纯静态，无数据库。双击 `index.html` 即可查看，也可直接部署到
GitHub Pages / 宝塔 / 任意静态空间。

## 文件

```
index.html   页面骨架
style.css    样式
app.js       逻辑
sites.js     ★ 数据全在这里
ico/         本地图标（可选，命名：域名.png）
```

## 平时只改 sites.js

### 站点信息

```js
var SITE = {
    name:   '我的导航',
    logo:   '🧭',            // emoji 或图片路径
    slogan: '精选每一个链接',
    footer: '本站仅收录公开网站链接',
    icp:    ''               // 备案号，留空不显示
};
```

### 加网址

```js
{
    name: '影视资源', icon: '🎬',
    groups: [
        { name: '在线', icon: '▶️', sites: [
            { name: '示例站', url: 'https://example.com', desc: '一句话简介' },
            // 加网址 = 复制上面一行改
        ]},
    ]
}
```

| 字段 | 必填 | 说明 |
|---|---|---|
| `name` | 是 | 网站名 |
| `url` | 是 | 必须带 `https://` |
| `desc` | 否 | 简介，留空显示域名 |
| `icon` | 否 | emoji 或图片路径，不填自动抓图标 |

**一级 + 二级**：`groups` 里的 `name` 填了就显示成「一级 · 二级」，
留空则只显示一级名。`CATS[i].icon` 是侧栏图标。

### 换搜索引擎

```js
var SEARCH_GROUPS = [
    { name: '常用', items: [
        { name: '百度', tpl: 'https://www.baidu.com/s?wd={q}' },
        // {q} 是关键词占位符
    ]},
];
```

### 改一言

```js
var HITOKOTO = '求知 · 探索 · 发现';
```

## 图标

顺序：**本地 `ico/域名.png` → 国内源 → 境外源 → 首字母占位图**

自动抓取时每级 4 秒超时，境外源卡住会跳下一个，不会白屏。
想最快就把图标放 `ico/` 目录（文件名 = 域名，如 `github.com.png`）。

## 一糖模式的三处切换

### ① 顶栏：菜单 + 下拉子菜单

```js
var TOP_MENU = [
    { name: '首页', url: '#' },
    { name: '垂直分类', url: '#', children: [
        { name: '今日热榜', url: '#' },
        // 有 children 就渲染成下拉
    ]},
];
```

鼠标悬停展开，点击也能展开（`url` 填 `#` 时点击只展开不跳转）。

### ② 侧栏：快捷项 + 一级展开二级

```js
var SIDE_QUICK = [
    { name: '首页',     icon: '🏠', url: '#' },
    { name: '每日热榜', icon: '🔥', url: '#' },
];
```

一级分类有二级时右侧显示 `›` 箭头，点击展开，**同时只展开一个**；
点二级会滚动到该区块并**自动激活对应的 pill**。

### ③ 区块标题右侧：二级 pills 点击切换

一级区块标题右边一排胶囊，点击即切换下面的网址，**不刷新、不滚动**。

- 只有 1 个分组时**不显示** pills（避免多余）
- 侧栏点二级会联动激活对应 pill

## 功能

- 侧栏固定 + 点击平滑滚动 + 滚动自动高亮当前分类
- 侧栏可折叠成图标条（mini 按钮），**状态记住**
- 超级搜索：6 组搜索引擎切换（百度/谷歌/GitHub/淘宝/B站…）
- 站内搜索：按 `/` 或点 🔍 唤出，搜名称 / 简介 / 分类 / 域名
- 深浅主题，记住选择；未选过跟随系统
- 响应式栅格：手机 2 列 → 平板 3 → 桌面 4 → 宽屏 5 → 超大 6
- 手机上侧栏变抽屉

## 部署

**GitHub Pages**：四个文件放仓库根目录 → Settings → Pages → `main` 分支。

**宝塔**：添加站点 → 数据库「不创建」、PHP「纯静态」→ 传文件到根目录
（先删掉宝塔自动生成的 `index.html`）。

## 注意

- 改了没变化？`Ctrl + Shift + R` 强刷
- 别给 `body` 加 `overflow-x: hidden`，会让 sticky 失效（现在用的 `clip`）

## 侧栏说明

- 默认状态由 `sites.js` 的 `SITE.sideMini` 决定：`true`=收起成图标条（鼠标移入临时展开、移出收回），`false`=始终展开。
- 底部「收起/展开」按钮已移除，侧栏只靠悬停临时展开，不再有按钮状态与视觉状态不一致的问题。
- 点击一级/二级分类后，滚动监听会短暂屏蔽约 900ms，避免滚动过去后高亮被视口里的其它分类抢走。

## 侧栏收放不闪烁的实现原理

悬停展开侧栏时如果闪烁，通常是两个原因叠加：

1. **逐帧重排**：侧栏变宽时，内部所有子元素（分类项、文字、间距）都要重新计算位置；
2. **模糊层重算**：`backdrop-filter` 所在元素尺寸变化时，浏览器每帧都要重算整块模糊。

本站的解法是把「布局」和「可见区域」解耦：

- 三个内容块（`.side-logo` / `.side-menu` / `.side-foot`）宽度恒定为 `--side-w`，**不随侧栏收放变化**；
- 毛玻璃放在 `.sidebar::before` 伪元素上，宽度同样恒定，模糊只计算一次；
- 侧栏本体只做 `width` 动画 + `overflow:hidden` 裁切，变化的只是「露出多少」。

因此收起态不需要任何 `.sidebar.mini .xxx` 子元素规则（全靠裁切隐藏），
`will-change`、动画期禁用过渡等补丁也都不需要。
图标居中靠校准 `padding-left`（分类/底部 20px、logo 17px）实现。

## 多语言切换

右下角「🌐」悬浮按钮（在「返回顶部」上方），点击弹出语言面板，当前语言带 ✓ 高亮。
选择后写入 localStorage，刷新保持。

内置 8 种：简体中文、繁體中文、English、日本語、한국어、Français、Deutsch、Español。

### 词典都在 `sites.js` 末尾

| 变量 | 作用 |
|---|---|
| `LANGS` | 语言列表（code / region / label / flag） |
| `UI_I18N` | 界面文案（按钮、placeholder、空状态等，`{n}` `{name}` 为占位符） |
| `CAT_I18N` | 分类名、二级分组名、菜单名 |
| `ENG_I18N` | 搜索引擎名（专有名词转罗马字） |
| `CITY_I18N` | 世界时钟城市名 |
| `DESC_I18N` | 站点简介（**以中文原文为 key**，只示范了部分，未收录的回退中文） |
| `SITE_I18N` | 站名 / 标语 / 页脚 |
| `HITO_I18N` | 各语言一言句子库 |

**扩展方法**：词典是「以中文为 key、按语言码取列」的结构。要加新语言：
1. 在 `LANGS` 里加一项
2. 在各词典每行末尾补上对应译文
没填的语言自动回退简体中文，不会出现空白。

站点名属专有名词，默认不翻译（想在 `CAT_I18N` 里补也可以）。
